# House Price Prediction

## Problem Statement
The aim of this project is to predict house prices based on various features such as area, bedrooms, bathrooms, stories, parking, and furnishing status using machine learning.

## Dataset
Housing dataset from Kaggle.

Dataset Link:
https://www.kaggle.com/datasets/yasserh/housing-prices-dataset

## Methodology
- Data preprocessing
- Label encoding
- Exploratory Data Analysis (EDA)
- Linear Regression model training
- Evaluation

## Results
- MAE: 979679
- MSE: 1771751116594
- RMSE: 1331071
- R² Score: 0.649

## Conclusion
The model predicts house prices with decent accuracy and can be improved further.
